**Some bugs only happen to some people. Find out who.**

Heisenbug is a public place to report bugs, confirm them on your own device and follow the fixes, for apps that are not open source. It gives a closed-source app public, GitHub-Issues-style tracking without the source code having to be public.

Pre-release and under development. https://heisenbughq.com

### How it will work

- **Report** a problem on the website, or from inside the app through a Heisenbug SDK.
- **Confirm** it on your own device with "Same here" or "Can't reproduce". The app version and device are filled in, so maintainers see who is affected.
- **Follow the fix** from triage to the release that ships it, then verify it yourself.

### Open source here

- [`heisenbug-design`](https://github.com/heisenbug-hq/heisenbug-design): design tokens, themes, the icon pack and the UI standards, published on npm as [`@heisenbughq/design`](https://www.npmjs.com/package/@heisenbughq/design).
- The JavaScript and TypeScript SDK and the Tauri plugin will be published here when they are ready.

### Security

Report vulnerabilities privately, never in a public issue: use GitHub private vulnerability reporting on the repository, or write to security@heisenbughq.com. See [`SECURITY.md`](https://github.com/heisenbug-hq/.github/blob/main/SECURITY.md).
